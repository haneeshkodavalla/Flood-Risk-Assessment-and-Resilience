
# Flood Risk Assessment and Community Resilience
### A GIS and Remote Sensing Study of Darbhanga, Bihar, India

## Project Overview
This project assesses flood hazards and community resilience across Darbhanga district, Bihar, using satellite imagery, geospatial analysis, and socioeconomic indicators. The study combines physical flood hazard mapping with community and infrastructure resilience assessment to support disaster risk management and planning.

## Objectives
- Identify flood-prone areas using Sentinel-1 SAR imagery.
- Analyze terrain using elevation and slope data.
- Evaluate community resilience using housing, literacy, healthcare, education, and road infrastructure indicators.
- Integrate hazard and resilience information at the administrative block level.
- Generate thematic GIS maps to support disaster preparedness.

## Tools and Technologies
- QGIS
- Sentinel-1 SAR satellite imagery
- Cartosat-1 Digital Elevation Model (DEM)
- OpenStreetMap and QuickOSM
- GIS raster analysis and zonal statistics
- Multi-criteria weighted index analysis

## Methodology
1. **Data collection:** Obtain satellite imagery, DEM, administrative boundaries, socioeconomic information, and infrastructure data.
2. **Preprocessing:** Process satellite images, prepare DEM tiles, and generate slope layers.
3. **Flood hazard mapping:** Identify inundation patterns and combine them with terrain indicators.
4. **Resilience assessment:** Create a composite index using social and physical infrastructure indicators.
5. **Zonal analysis:** Aggregate physical hazard measurements by administrative block.
6. **Map preparation:** Develop flood hazard, resilience, and composite index maps.

## Study Area
Darbhanga district, Bihar, India.
